五、画板3：分支流程图

展示完整的6章剧情分支结构，体现叙事架构设计能力。

┌─────────────┐ │ 序章：入宫 │ │ (3个选项) │ └──────┬──────┘ │ ┌───┼───┐ ▼ ▼ ▼ ┌────┐┌────┐┌────┐ │诗才││谦退││试探│ │+10 ││+5 ││+15 │ │好感 ││智慧 ││心机 │ └─┬──┘└─┬──┘└─┬──┘ │ │ │ └─────┼─────┘ ▼ ┌─────────────┐ │ 第二章：御花园 │ │ (4个选项) │ └──────┬──────┘ │ ┌───┼───┐ ▼ ▼ ▼ ... (以此类推)

绘制要点

· 每个节点标注章节名和选项数量
· 箭头旁标注属性变化（如+10好感）
· 用颜色区分不同路线（红色=好感线，蓝色=智慧线，紫色=心机线）
· 标注锁定选项的解锁条件

六、画板4：状态流转图

展示"选择→属性变化→解锁新内容"的系统设计。

┌──────────┐ ┌──────────┐ ┌──────────┐ │ 玩家选择 │───▶│ 属性计算 │───▶│ 解锁判断 │ │ "反问皇帝"│ │ 心机+15 │ │ 心机≥40? │ └──────────┘ │ 好感-5 │ └────┬─────┘ └──────────┘ │ ┌──────┴──────┐ ▼ ▼ ┌─────────┐ ┌─────────┐ │ YES:解锁 │ │ NO:锁定 │ │ 隐藏选项 │ │ 显示条件 │ └─────────┘ └─────────┘

绘制要点

· 展示完整的状态流转逻辑
· 标注每个节点的输入/输出
· 用判断节点（菱形）表示条件分支
· 展示属性阈值如何影响游戏内容
