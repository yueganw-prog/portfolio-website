灵
CASE STUDY 02 GAME AI · PERSONAL DESIGN STUDY

项目概述

个人设计研究：以开放都市RPG品类为研究对象，系统推演RPG中NPC AI的行为架构与落地方法——让NPC拥有自己的生活，让队友与车流成为玩家可感知、可利用的玩法，并回答"AI需求如何变成可上线的AI行为"。

核心设计

  • 分层架构　感知 / 情境 / 决策 / 行为 / 表现五层拆分，黑板共享数据，明确策划与程序的模块边界
  • 决策模型　FSM · 行为树 · Utility AI 按角色类型混用：行为树做骨架、Utility做打分、FSM做原子兜底
  • 开放世界生态　日程系统 + 地点行为池 + 记忆系统，NPC不依赖玩家"自转"，任务优先级可随时覆盖
  • 队友AI　战斗协作 / 指令响应 / 情感权重三层设计——队友要可靠，但不能比玩家聪明
  • 车辆AI　交通流与玩法车分层，车道图独立寻路，LOD式精度递减平衡性能与都市可信度
  • 落地流程　AI需求 → 策划设计 → 程序/AI协作 → 测试调优的完整工作方法，策划交付可执行的配置件

方法与验证
