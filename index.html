作品一

AI互动叙事Demo

《凤谋》— 古风宫廷AI互动叙事体验

项目概述

基于大语言模型的分支叙事游戏Demo。玩家扮演新入宫的嫔妃，通过与AI驱动的NPC对话，在宫廷博弈中做出选择，最终走向不同结局。

核心设计

  • 角色卡系统　为每个NPC定义性格、立场、秘密，确保AI输出符合角色设定
  • 分支叙事引擎　玩家选择影响角色关系值，触发不同剧情线
  • Prompt约束机制　通过结构化指令控制AI输出格式和内容边界
  • 多结局系统　根据累积选择计算结局走向，提供3种以上结局

HTML/CSS/JS LLM API Prompt Engineering
